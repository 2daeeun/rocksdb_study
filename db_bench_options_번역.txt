사용법 (USAGE):  
./db_bench [OPTIONS]...

  /usr/src/debug/gflags/gflags-2.2.2/src/gflags.cc에서의 플래그 (Flags):  
    -flagfile (파일에서 플래그를 로드합니다)  
      유형: string 기본값: ""  
    -fromenv (환경 변수에서 플래그를 설정합니다 [예: 'export FLAGS_flag1=value'])  
      유형: string 기본값: ""

    -undefok (쉼표로 구분된 플래그 이름 목록으로, 프로그램에서 해당 플래그를 정의하지 않아도 명령줄에서 지정할 수 있습니다.  
      중요: 이 목록의 플래그 중 인수를 가진 플래그는 반드시 flag=value 형식을 사용해야 합니다.)  
      유형: string 기본값: ""

  -advise_random_on_open (테이블 파일 열기에 대해 랜덤 액세스를 권장합니다.)  
    유형: bool 기본값: true  
  -allow_concurrent_memtable_write (여러 작성자가 메모리 테이블을 병렬로 업데이트할 수 있도록 허용합니다.)  
    유형: bool 기본값: true  
  -allow_data_in_errors (true로 설정하면 LOG 파일에 키나 값을 기록하는 등의 데이터 로깅을 허용합니다.)

  -arena_block_size (Arena 메모리 할당에서 하나의 블록 크기(바이트 단위).)  
    유형: int64 기본값: 0  
  -async_io (true로 설정하면 RocksDB가 내부 자동 사전 읽기(prefetching)를 비동기적으로 수행합니다.)

  -auto_prefix_mode (seek 벤치마크를 위한 auto_prefix_mode를 설정합니다.)  
    유형: bool 기본값: false  
  -auto_readahead_size (true로 설정하면 RocksDB가 Scan 중 사전 읽기 크기를 자동으로 조정합니다.)

  -avoid_flush_during_recovery (true로 설정하면 가능한 경우 복구된 WAL 데이터를 플러시하지 않습니다.)

    유형: uint64 기본값: 0  
  -batch_size (배치 크기)  
    유형: int64 기본값: 1  
  -benchmark_read_rate_limit (0이 아닌 경우, db_bench가 RocksDB의 읽기를 속도 제한합니다. 이는 초당 작업 횟수(ops/second)로 지정된 전역 속도입니다.)  
    유형: uint64 기본값: 0  
  -benchmark_write_rate_limit (0이 아닌 경우, db_bench가 RocksDB로의 쓰기를 속도 제한합니다. 이는 초당 바이트 수(bytes/second)로 지정된 전역 속도입니다.)  
    유형: uint64 기본값: 0  

  -benchmarks (쉼표로 구분된 작업 목록으로, 지정된 순서대로 실행됩니다. 사용 가능한 벤치마크:  
    - fillseq -- 비동기 모드에서 키 순서대로 N개의 값을 씁니다.  
    - fillseqdeterministic -- 지정된 키 순서대로 N개의 값을 쓰며 LSM 트리의 구조를 유지합니다.  
    - fillrandom -- 비동기 모드에서 랜덤 키 순서대로 N개의 값을 씁니다.  
    - filluniquerandomdeterministic -- 랜덤 키 순서대로 N개의 값을 쓰며 LSM 트리의 구조를 유지합니다.  
    - overwrite -- 비동기 모드에서 랜덤 키 순서대로 N개의 값을 덮어씁니다.  
    - fillsync -- 동기 모드에서 랜덤 키 순서대로 N/1000개의 값을 씁니다.  
    - fill100K -- 비동기 모드에서 랜덤 순서로 N/1000개의 100K 값을 씁니다.  
    - deleteseq -- 순차적으로 N개의 키를 삭제합니다.  
    - deleterandom -- 랜덤 순서로 N개의 키를 삭제합니다.  
    - readseq -- N번 순차적으로 읽습니다.  
    - readtocache -- 데이터베이스를 순차적으로 읽는 1개의 쓰레드.  
    - readreverse -- N번 역순으로 읽습니다.  
    - readrandom -- 랜덤 순서로 N번 읽습니다.  
    - readmissing -- 랜덤 순서로 누락된 N개의 키를 읽습니다.  
    - readwhilewriting -- 1개의 작성자가 있고, N개의 쓰레드가 랜덤 읽기를 수행합니다.  
    - readwhilemerging -- 1개의 병합 작업자, N개의 쓰레드가 랜덤 읽기를 수행합니다.  
    - readwhilescanning -- 1개의 쓰레드가 전체 테이블을 스캔하고, N개의 쓰레드가 랜덤 읽기를 수행합니다.  
    - readrandomwriterandom -- 랜덤 읽기와 쓰기를 수행하는 N개의 쓰레드.  
    - updaterandom -- 랜덤 키에 대해 읽기-수정-쓰기를 수행하는 N개의 쓰레드.  
    - xorupdaterandom -- 읽기-XOR-쓰기를 수행하는 N개의 쓰레드.  
    - appendrandom -- 값이 증가하는 방식으로 읽기-수정-쓰기를 수행하는 N개의 쓰레드.  
    - mergerandom -- 병합 연산자를 사용하여 updaterandom/appendrandom과 동일한 작업 수행. merge_operator와 함께 사용해야 함.  
    - readrandommergerandom -- 랜덤 읽기 또는 병합 작업을 N번 수행. merge_operator와 함께 사용해야 함.  
    - newiterator -- 반복적으로 iterator를 생성.  
    - seekrandom -- N번 랜덤 탐색을 수행하며, 탐색마다 seek_nexts를 호출.  
    - seekrandomwhilewriting -- seekrandom과 1개의 쓰레드로 덮어쓰기.  
    - seekrandomwhilemerging -- seekrandom과 1개의 쓰레드로 병합 수행.  
    - crc32c -- <블록 크기> 데이터를 반복적으로 crc32c 수행.  
    - xxhash -- <블록 크기> 데이터를 반복적으로 xxHash 수행.  
    - xxhash64 -- <블록 크기> 데이터를 반복적으로 xxHash64 수행.  
    - xxh3 -- <블록 크기> 데이터를 반복적으로 XXH3 수행.  
    - acquireload -- N*1000번 로드 수행.  
    - fillseekseq -- 키를 순차적으로 작성한 후, 각 키로 탐색하며 읽습니다.  
    - randomtransaction -- N개의 랜덤 트랜잭션을 실행하고 정확성을 검증.  
    - randomreplacekeys -- 이전 버전을 삭제하고 새 버전을 삽입하며 N개의 키를 랜덤으로 교체.  
    - timeseries -- 1개의 작성자가 시계열 데이터를 생성하며, 여러 독자가 랜덤 읽기를 수행.  
      
Meta operations:  
  - compact -- 데이터베이스(DB)의 전체 압축을 수행합니다. 여러 번 수행하는 경우 무작위로 선택합니다.  
  - compactall -- 데이터베이스(DB)의 전체 압축을 수행합니다.  
  - compact0 -- L0을 L1으로 압축합니다.  
  - compact1 -- L1을 L2로 압축합니다.  
  - waitforcompaction -- 압축이 (아마도) 완료될 때까지 일시 중지합니다.  
  - flush -- 메모리 테이블(memtable)을 플러시합니다.  
  - stats -- 데이터베이스(DB) 통계를 출력합니다.  
  - resetstats -- 데이터베이스(DB) 통계를 재설정합니다.  
  - levelstats -- 레벨별 파일 및 바이트 수를 출력합니다.  
  - memstats -- 메모리 테이블(memtable) 통계를 출력합니다.  
  - sstables -- SSTable 정보를 출력합니다.  
  - heapprofile -- 힙 프로파일을 덤프합니다(포트에서 지원하는 경우).  
  - replay -- `trace_file`로 지정된 트레이스 파일을 재생합니다.  
  - getmergeoperands -- 특정 키에 대해 정렬된 정수 리스트의 병합 레코드를 대량으로 삽입한 후, 다른 키의 조회 성능을 비교합니다.  
    Get 후 정렬된 큰 리스트에서 이진 검색을 수행하는 것과, GetMergeOperands 후 정렬된 서브 리스트에서 검색하는 성능을 비교합니다.  
    MergeOperator로는 `sortlist.h`를 사용합니다.  
  - readrandomoperands -- `GetMergeOperands()`를 사용하여 랜덤 키를 읽습니다. 작업에는 드물지만 가능한 재시도가 포함되며, 이는  
    쓰레드가 본 적이 없는 키(처음에는 8개)를 만났을 때 `Status::Incomplete()`가 발생한 경우입니다.  
  - backup -- 현재 데이터베이스(DB)를 백업하고, 새 백업이 올바른지 확인합니다. 속도 제한은 `--backup_rate_limit`를 통해 지정할 수 있습니다.  
  - restore -- 최신 백업에서 데이터베이스(DB)를 복원합니다. 속도 제한은 `--restore_rate_limit`를 통해 지정할 수 있습니다.  
  - approximatememtablestats -- `GetApproximateMemTableStats`의 정확도를 테스트합니다.  
    이상적으로는 `fillrandom` 이후 수행되며, 실제 정답은 `batch_size`입니다.  
  - 기본값:  
    `"fillseq,fillseqdeterministic,fillsync,fillrandom,filluniquerandomdeterministic,overwrite,readrandom,newiterator,newiteratorwhilewriting,seekrandom,seekrandomwhilewriting,seekrandomwhilemerging,readseq,readreverse,compact,compactall,flush,compact0,compact1,waitforcompaction,multireadrandom,mixgraph,readseq,readtorowcache,readtocache,readreverse,readwhilewriting,readwhilemerging,readwhilescanning,readrandomwriterandom,updaterandom,xorupdaterandom,approximatesizerandom,randomwithverify,fill100K,crc32c,xxhash,xxhash64,xxh3,compress,uncompress,acquireload,fillseekseq,randomtransaction,randomreplacekeys,timeseries,getmergeoperands,readrandomoperands,backup,restore,approximatememtablestats"`
